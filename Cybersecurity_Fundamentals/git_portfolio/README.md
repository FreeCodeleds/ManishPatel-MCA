## 📌 Overview

This portfolio documents practical lab experiments, technical writeups, security tooling scripts, and conceptual notes developed as part of the **Cybersecurity Fundamentals** coursework. The objective is to demonstrate hands-on competencies in network defense, cryptographic primitives, vulnerability assessment, and foundational security engineering.
